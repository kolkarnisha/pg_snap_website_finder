# PG Finder

A modern React + Vite website for discovering verified PG accommodations in Marathahalli.

Live demo: https://pg-finder-ev4l.vercel.app/

## Features

- Browse verified PG listings
- Search and filter by budget, gender, and location
- View detailed PG information and amenities
- Responsive layout for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
